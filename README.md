# ☣️ Настольная психологическая игра «Бункер» (Онлайн)

Веб-версия популярной психологической дискуссионной игры **«Бункер»** для игры с друзьями через браузер с любого телефона, планшета или компьютера.

---

## 🚀 Постоянная бесплатная ссылка 24/7 (Без VPN!)

Раньше запуск через локальные туннели (Cloudflare / trycloudflare) требовал включения VPN у игроков из РФ из-за блокировок провайдеров. 
Благодаря загрузке кода на **GitHub**, теперь можно получить **собственный постоянный сервер 24/7**, который работает быстро, надежно и **БЕЗ VPN** для всех игроков со смартфонов и ПК!

### Быстрый запуск постоянного сайта в 1 клик:
Нажмите на прямую ссылку для развертывания репозитория на бесплатном облаке:
👉 **[Развернуть Бункер на Render (1 клик)](https://render.com/deploy?repo=https://github.com/AnekkenA/Kunker)**

Либо вручную:
1. Зайдите на бесплатный сервис [Render.com](https://render.com) и войдите через свой аккаунт **GitHub** (`AnekkenA`).
2. Нажмите синюю кнопку **«New +»** ➔ выберите **«Web Service»**.
3. Выберите ваш репозиторий `AnekkenA/Kunker` (или вставьте ссылку `https://github.com/AnekkenA/Kunker.git`).
4. Нажмите **«Deploy Web Service»** — все параметры подтянутся из файла `render.yaml` автоматически.
5. Через минуту у вас появится постоянная защищенная ссылка вида:
   `https://kunker-xxxx.onrender.com`
6. Отправьте эту ссылку друзьям — она работает 24/7, не требует включенного ПК и открывается без VPN!

## ⚙️ Настройки комнат и автоочистка (Лимиты сервера)

- **Лимит комнат:** максимум **4 бункера** одновременно. Это гарантирует быструю и стабильную работу даже на бесплатном тарифе.
- **Автоосвобождение через 5 минут:** если в бункере нет активности (никто не ходит, не открывает карты, не голосует) в течение **5 минут**, комната автоматически закрывается и освобождается для других игроков.
- **Быстрая очистка пустых комнат:** если все игроки закрыли вкладку или вышли, комната освобождается уже через 2 минуты.
- **Счетчик свободных комнат:** на стартовом экране в реальном времени отображается количество доступных убежищ: `🏕️ Свободно бункеров: X из 4`.

## 🔑 Комнаты, короткие коды и защита паролем

Чтобы игроки из разных компаний не попадали в один бункер и не мешали друг другу:

### 1. Короткие коды комнат (например `4821`):
- При создании бункера система генерирует удобный **4-значный код** (или вы можете ввести свой).
- Код легко продиктовать в Discord / Telegram: *«Заходи в бункер 4821»*.
- При входе по прямой ссылке (`https://ваш-сайт/?room=4821`) код подставляется автоматически.

### 2. Защита бункера паролем:
- Мастер при создании комнаты может задать **пароль** (например `1234` или любое слово).
- Никто посторонний не сможет зайти в ваш бункер без ввода пароля.
- Мастер в лобби в панели «Параметры убежища» может в любой момент изменить пароль или снять его.

### 3. Блокировка шлюза («Запереть бункер»):
- В лобби Мастер может поставить галочку **«Запереть шлюз»**.
- Новые игроки не смогут подключиться к комнате, пока Мастер не откроет шлюз.
- Ранее подключенные игроки при перезагрузке страницы всегда могут восстановить связь.

### 4. Удаление лишних игроков:
- Мастер в лобби может в один клик исключить любого лишнего участника кнопкой **«✕ Кикнуть»**.

## 📱 Как играть с друзьями:

1. **Мастер**: нажимает вкладку **«🎲 Создать бункер»**, вводит свой позывной, код комнаты и (по желанию) пароль.
2. **Приглашение друзей**:
   - Нажмите в лобби кнопку **«📱 Ссылка для подключения»**.
   - Нажмите **«💬 Скопировать приглашение для друзей»** — в буфер скопируется готовое сообщение с кодом, паролем и ссылкой для Telegram / WhatsApp.
   - Либо покажите **QR-код** на экране для сканирования камерой смартфона.
3. **Игроки**: переходят по ссылке со своего смартфона или вводят код комнаты на главной странице.
4. Игра начинается прямо в браузере — устанавливать приложения не нужно!

## 💻 Локальный запуск на компьютере (Офлайн / Домашний Wi-Fi):

Если вы хотите запустить игру локально на своем ПК:
1. Запустите файл `start_online.bat` (или ярлык «Бункер»).
2. Для игры в одной домашней Wi-Fi сети выберите локальный адрес (`http://192.168.x.x:3000`).
