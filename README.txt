================================================================================
                    ИНСТРУКЦИЯ ПО ЗАПУСКУ ИГРЫ «БУНКЕР»
================================================================================

В папке находится ОДИН главный файл для запуска:
«Запустить_Бункер.bat»

Другим игрокам ничего скачивать не нужно — они подключаются через свой браузер.


================================================================================
 КАК ЗАПУСТИТЬ ИГРУ
================================================================================

1. Дважды кликните по файлу «Запустить_Бункер.bat».
2. В появившемся окне выберите нужный способ подключения:

   [1] ОБЩИЙ WI-FI / ТОЧКА ДОСТУПА С ТЕЛЕФОНА
       (Для смартфонов и ПК в одной сети / комнате / квартире)

   [2] RADMIN VPN
       (Для игроков со своих ПК из других городов через сеть Radmin)

   [3] Открыть порт 3000 в Брандмауэре Windows
       (Разрешить входящие подключения в системе при первом запуске)


================================================================================
 СПОСОБ 1: ПОДКЛЮЧЕНИЕ ПО WI-FI / ТОЧКЕ ДОСТУПА (СМАРТФОНЫ И ПК)
================================================================================

УСЛОВИЕ: Компьютер и телефоны подключены к одной Wi-Fi сети (или компьютер
подключен к мобильной точке доступа, раздаваемой с телефона).

1. В меню выберите [1] (или просто нажмите Enter).
2. На компьютере автоматически откроется браузер (http://localhost:3000). Введите имя (Мастер).
3. На смартфонах игроков:
   - Вариант А: Нажмите на ПК «Ссылка для подключения» и наведите камеру
     телефона на QR-код на экране монитора.
   - Вариант Б: Откройте браузер на телефоне (Chrome / Safari) и введите адрес:
     http://192.168.22.56:3000
4. Игроки вводят свои никнеймы и нажимают «Войти в бункер» — они мгновенно
   появляются у вас в шлюзе бункера.

ВАЖНО: Если телефон не открывает страницу:
- Выберите пункт [3] в меню для открытия порта 3000 в защите Windows.


================================================================================
 СПОСОБ 2: ПОДКЛЮЧЕНИЕ ЧЕРЕЗ RADMIN VPN (ДРУЗЬЯ С ПК ИЗ ДРУГИХ ГОРОДОВ)
================================================================================

УСЛОВИЕ: Вы и ваши друзья подключены к одной комнате в программе Radmin VPN.

1. Убедитесь, что Radmin VPN включен.
2. В меню выберите [2].
3. Друзья открывают любой браузер на своем компьютере и вводят ваш адрес:
   http://26.191.152.48:3000
4. Вводят имя и сразу оказываются с вами за одним игровым столом.
